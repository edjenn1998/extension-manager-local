# Credits and upstream attribution

Extension Manager Local is built directly on **[Extension Manager](https://github.com/mjakeman/extension-manager)**, created by **Matthew Jakeman**, with **Óscar Fernández Díaz** and the project's many other contributors.

The GNOME-native application, original interface, Installed/Browse tabs, online extension browsing/search/installation, and existing extension management are upstream work. This fork's only added extension-management capability is graphical installation and replacement/upgrading from **local ZIP files**.

The purple icon is a recoloring of the original Extension Manager artwork, with its shapes and proportions unchanged. The icon's upstream history credits Matthew Jakeman and daudix-UFO. Original contributor, translator, and artwork credits are retained in the application, source headers, and `README.upstream.md`.
